# Architecture decisions

* [ADR-0001: Feature-sliced MVVM](adr-0001-feature-sliced-mvvm.md) - thin routes and feature ownership.
* [ADR-0002: Capability consumption](adr-0002-capability-consumption.md) - compatibility endpoint, not a second catalog.
* [ADR-0003: Shared catalog and packs](adr-0003-shared-catalog-and-packs.md) - one product, three pack projections, no edition UI forks.
* [ADR-0004: Build profile exclusion](adr-0004-build-profile-exclusion.md) - per-profile artifacts and the published catalog dependency.
* [ADR-0005: Package-owned capability surfaces](adr-0005-package-owned-capability-surfaces.md) - frontend surface consumption from the versioned catalog package.
* [ADR-0006: Capability package provenance](adr-0006-capability-package-provenance.md) - deterministic integrity checks for the vendored backend artifact.
