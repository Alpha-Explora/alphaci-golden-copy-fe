# Composition packs

* [Pack contract](pack-contract.md) - common headings and status vocabulary.
* [Pack template](pack-template.md) - copyable current-state structure.
* [SaaS pack](saas/) - SaaS composition reference.
* [EDU pack](edu/) - EDU composition reference.
* [Enterprise pack](enterprise/) - Enterprise composition reference.

Pack files are comparable documentation artifacts generated from the shared catalog snapshot. Each profile lists the same capabilities in the same order. Differences belong in status (`not-implemented` versus `not-applicable`), deployment scope, and explicit non-support. Packs do not create separate frontend implementations or edition-specific route trees.
